# Manual de usuario — guía inicial

## Ingreso
1. Abrir la URL del frontend indicada por el administrador.
2. Iniciar sesión con la cuenta asignada.
3. Si no dispone de permisos para una acción, solicitar habilitación al administrador.

## Productos e inventario
- Consultar productos, SKU y existencias disponibles.
- Registrar movimientos únicamente con la bodega correcta.
- Antes de un conteo físico, confirmar ubicación y fecha de corte.
- Las alertas de stock requieren configuración de umbrales y monitor activo.

## Cotizaciones y pedidos
- Crear cotización con cliente, productos y cantidades.
- Revisar precios y descuentos antes de aprobar.
- Convertir una cotización aceptada una sola vez; no repetir el clic si la red tarda sin verificar el resultado.
- Revisar estado del pedido y bodega de despacho.
- Los pedidos enviados se gestionan mediante devolución, no cancelación directa.

## Pagos, cartera y devoluciones
- Registrar comprobantes con referencia única.
- Confirmar saldo y documento de origen antes de registrar un pago.
- Para devoluciones parciales, revisar cantidades ya devueltas y ubicación de reintegro.

## Soporte
- Registrar fecha, usuario, módulo, operación y mensaje de error (sin contraseñas ni tokens).
- Los datos reales requieren validación de roles, respaldo y pruebas antes de habilitar producción.

> Esta guía describe los flujos previstos; las pantallas y su comportamiento final deben contrastarse en la etapa de pruebas funcionales.
